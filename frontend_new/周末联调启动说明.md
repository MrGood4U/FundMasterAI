# FundMasterAI 前后端周末联调启动说明

本文适用于 Windows CMD。需要同时打开 3 个 CMD 窗口，并保持三个窗口持续运行。

## 一、启动前确认

项目目录：

```text
C:\Users\admin\Desktop\项目\code\new\FundMasterAI
```

首次运行时安装依赖：

```bat
python -m pip install flask flask-openapi3 akshare pandas numpy efinance okx
python -m pip install -U "flask-openapi3[swagger,redoc]"
```

如果新闻后端仍提示缺少依赖，可再执行：

```bat
python -m pip install flask akshare pandas
```

## 二、打开三个 CMD

### CMD 1：启动行情后端（5001）

```bat
cd /d C:\Users\admin\Desktop\项目\code\new\FundMasterAI\backend\market_backend
python app.py
```

看到下面的内容表示服务已启动：

```text
Running on http://127.0.0.1:5001
```

### CMD 2：启动新闻后端（5000）

```bat
cd /d C:\Users\admin\Desktop\项目\code\new\FundMasterAI\backend\news_backend
python app.py
```

看到下面的内容表示服务已启动：

```text
Running on http://127.0.0.1:5000
```

### CMD 3：启动前端和接口代理（8080）

```bat
cd /d C:\Users\admin\Desktop\项目\code\new\FundMasterAI\frontend_new
python .\scripts\dev-server.py
```

看到下面三行表示前端和代理已启动：

```text
Frontend: http://127.0.0.1:8080
Proxy: /api/market -> http://127.0.0.1:5001
Proxy: /api/news -> http://127.0.0.1:5000
```

不要使用 `python -m http.server 8080`，它只能展示静态页面，不能代理后端接口，会产生跨域问题。

## 三、浏览器打开三个页面

三个 CMD 都启动后，在浏览器分别打开：

1. 新闻页：<http://127.0.0.1:8080/index.html>
2. 基金详情页：<http://127.0.0.1:8080/fund-deep-dive.html>
3. 行情页：<http://127.0.0.1:8080/market-hub.html>

不要直接在浏览器地址栏打开 `/api/market/stock/a/all_spot`。该接口要求 `POST` 请求，直接打开会发送 `GET` 请求并显示 `Method Not Allowed`，这是正常现象。

## 四、确认真实接口已经连通

1. 按 `F12` 打开开发者工具，切换到“网络（Network）”。
2. 刷新页面，筛选 `Fetch/XHR`。
3. 确认请求状态为 `200`：

| 页面 | 应看到的接口 |
|---|---|
| `index.html` | `/api/news/stock/get_recent_news` |
| `fund-deep-dive.html` | `/api/market/fund_public/real_time_get_one`、`/api/market/fund_public/hist` |
| `market-hub.html` | `/api/market/stock/a/all_spot` |

4. 点开请求查看“响应（Response）”，能看到后端返回的 JSON 数据，才表示真实接口调用成功。

页面上的接口状态提示也会显示连接情况。页面仍保留部分静态展示内容，所以不能仅凭页面有数据显示就判断接口成功，应以 Network 中请求返回 `200` 为准。

## 五、常见问题

### 1. `502 Bad Gateway`

对应后端没有启动或已经退出：

- `/api/market/...` 报 502：检查 CMD 1。
- `/api/news/...` 报 502：检查 CMD 2。

### 2. `500 Internal Server Error`

前端代理已经连到后端，但后端取数失败。查看 CMD 1 或 CMD 2 的报错。若出现 `eastmoney.com`、`RemoteDisconnected`、`ProxyError`，通常是 AkShare 访问外部数据源失败，需要检查当前网络、代理或稍后重试，不是前端接口地址错误。

### 3. NumPy 版本不兼容

若出现 `A module that was compiled using NumPy 1.x cannot be run in NumPy 2.x`，在对应后端 CMD 中停止服务后执行：

```bat
python -m pip install "numpy<2" --force-reinstall
```

然后重新执行 `python app.py`。

### 4. 端口被占用

检查端口占用：

```bat
netstat -ano | findstr :5000
netstat -ano | findstr :5001
netstat -ano | findstr :8080
```

关闭旧服务后重新启动。三个服务停止时，在各自 CMD 窗口按 `Ctrl+C`。

## 六、联调结束

依次在三个 CMD 窗口按 `Ctrl+C`，确认服务停止即可。
